Privacy Policy for JustAnotherPassword

JustAnotherPassword does not collect, sell, share, transmit, or store personal data on any external server.

All password generation occurs locally in your browser using browser-native cryptographic randomness. Generated passwords are not sent to the developer, to any third party, or to any remote service.

The extension temporarily uses Chrome local storage only to pass the generated password from the generator popup to the password display window. This temporary value is cleared automatically after a short timeout or when the user closes the password display window using the extension's close button.

The extension uses clipboard write access only when the user chooses to copy a generated password or when the extension attempts to overwrite the clipboard after the temporary password period expires. Browser security rules may prevent clipboard changes when the password display window is not focused.

This extension does not access browsing history, page content, location, camera, microphone, contacts, files, or user accounts.

If you have any questions, please contact the developer via the Chrome Web Store listing page.
