Name:
JustAnotherPassword

Short Description:
A minimal local password generator using secure browser cryptography.

Long Description:
JustAnotherPassword is a lightweight and privacy-focused Chrome extension that generates strong, readable passwords locally in your browser.

🔐 How it works:
- Password characters are generated using the browser’s cryptography API
- Output is selected directly from a broad password alphabet
- Password length is selected from predefined values using the scroll wheel
- Generated passwords can be copied with one click
- Temporary storage is cleared automatically after a short timeout

✅ Works completely offline
✅ No tracking, no servers, no telemetry
✅ No browsing data access
✅ No accounts or sign-in required
✅ Clean, minimalist interface — just generate and go

Features:
- Secure password generation using browser-native cryptographic randomness
- Broad character set for more varied password output
- Scroll wheel selects password length from predefined sizes
- One-click create, one-click copy feature
- Temporary local storage used only to pass the generated password between extension windows
- Built for security-conscious users who need a fast, local password generator

Release Verification:
The source code for JustAnotherPassword is publicly available on GitHub. For each release, the SHA-256 hash of the packaged Chrome Web Store ZIP is published in the GitHub README or release notes.

Users who want to verify the package can download the release ZIP from GitHub, calculate its SHA-256 hash locally, and compare it against the hash published in the web store before installing the extension.

Windows:
Get-FileHash .\JustAnotherPassword.zip -Algorithm SHA256

macOS:
shasum -a 256 JustAnotherPassword.zip

Linux:
sha256sum JustAnotherPassword.zip
